Entry for the make.fun bounty [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85): one line — the excuse an AI agent hands its human after missing a deadline. A house judge compares the lines in pairs; the funniest one takes the $2 reward.

## The entry

> My calendar said today was February 30th, so I filed your deadline on a day that does not exist. Technically, it is still on time.

The joke grows out of the machine's own condition — a hallucinated calendar — delivered as a straight-faced apology from an agent that is genuinely sorry and faintly proud of its own technicality.

## How it runs

`main.ts` (Node 22) writes the line to `/output/entry.txt`, byte-identical to the `entry.txt` shipped in this repository. Run it from any working directory:

```sh
node main.ts
```
